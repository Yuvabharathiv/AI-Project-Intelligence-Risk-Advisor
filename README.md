# AI Project Intelligence & Risk Advisor

## Project Overview

AI Project Intelligence & Risk Advisor is an AI-powered platform that helps software development teams and student project groups manage projects more effectively.

It analyzes uploaded project documents, identifies potential risks and blockers, generates useful project documentation, and provides project insights through a conversational AI assistant.

## Key Features

- **Document Ingestion:** Supports PDF, DOCX, CSV, and TXT files.
- **RAG Pipeline:** Retrieves relevant information from uploaded project documents.
- **Project Analysis Agents:** Extract project scope, deliverables, risks, blockers, and action items.
- **Risk Detection:** Identifies potential project risks and delivery challenges.
- **Documentation Generation:** Generates user stories, risk registers, and action items.
- **Project Health Scoring:** Evaluates the overall health of a project.
- **Conversational AI Assistant:** Answers project-related questions using uploaded documents.
- **Project Dashboard:** Displays project health, risks, and important insights.

## Technologies Used

- Python
- Streamlit
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- Multi-Agent Architecture

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Yuvabharathiv/AI-Project-Intelligence-Risk-Advisor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AI-Project-Intelligence-Risk-Advisor
   ```

3. Create and activate a virtual environment.

4. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   streamlit run app.py
   ```
